# Estrutura de proposta

Seções que aparecem na maioria dos formulários de projeto cultural. A ordem e os
nomes mudam por edital — siga sempre o formulário oficial.

| Seção | O que precisa entregar |
|---|---|
| Apresentação / resumo | O quê, onde, quando, para quem, em 3–5 frases. Primeira impressão do avaliador. |
| Justificativa | Por que este projeto, por que agora, por que neste território, por que esta equipe. Dados e contexto, não adjetivos. |
| Objetivos | Geral (1) + específicos (3–6), verificáveis. |
| Metas | Números: público, apresentações, oficinas, horas, empregos, alcance de mídia. Cada meta com forma de comprovação. |
| Público-alvo | Perfil, faixa etária, estimativa, como será alcançado. |
| Democratização de acesso | Gratuidade/ingresso popular, cotas, ações em periferias, transporte, horários. |
| Acessibilidade | Física, comunicacional (Libras, audiodescrição, legendas), atitudinal; com orçamento. |
| Plano de divulgação | Canais, peças, cronograma, assessoria; aplicação de marcas conforme o edital. |
| Cronograma | Pré-produção, produção, pós-produção, prestação de contas. |
| Orçamento | Rubricas por etapa; respeitar tetos percentuais; valores defensáveis. |
| Ficha técnica | Funções, nomes, minicurrículos focados no que o projeto exige. |
| Contrapartidas | As exigidas pelo edital, concretas e orçadas. |
| Portfólio / histórico | Comprovação de realizações anteriores do proponente e da equipe. |
